## Описание

**Vanguardl Deployment** - бот мониторинга для Discord и Telegram. Он следит за серверами и сайтом Muhamed Abs, держит запущенных ботов на машинах и пишет в канал, если что-то пошло не так.

Подходит для:

* мониторинга серверов за хостинг-панелью
* поддержания ботов на машинах, которые останавливаются при неактивности
* оповещений о статусе в канале Discord или чате Telegram

Один процесс запускает обоих ботов и единый цикл проверок. База данных не нужна: состояние хранится в памяти.

---

## Возможности

* Работает в Discord и Telegram одновременно (любой из них можно отключить)
* Проверка каждой машины по SSH: аптайм, нагрузка, память и диск
* Запуск команды бота на машине, если она не запущена (tmux, с запасным вариантом без него)
* Проверка сайта со временем ответа
* Оповещения, когда сервер или сайт упал, снова работает или бота пришлось перезапустить
* Оповещение приходит только после нескольких неудачных проверок подряд, поэтому единичный сбой его не вызывает
* Команда `/ai` для вопросов к любому OpenAI-совместимому API
* Команда `/history` с последними коммитами GitHub
* Статус в Discord показывает, сколько машин онлайн
* Минималистичный вывод в терминал: без ключей, токенов и трейсбеков, а секреты маскируются и в файле логов

## Команды

| Команда    | Что делает                                              |
| ---------- | ------------------------------------------------------- |
| `/start`   | о боте, пинг, создатель и список команд                 |
| `/info`    | подробный статус машин и сайта                          |
| `/check`   | запустить проверку прямо сейчас и разбудить серверы     |
| `/project` | о проекте Muhamed Ads                                   |
| `/history` | последние коммиты из GitHub                             |
| `/ai`      | задать вопрос ИИ, например `/ai What is Pterodactyl?`   |

В Discord это слеш-команды (только на серверах). В Telegram они работают в чатах и каналах.

---

## Как это работает

1. Каждые `interval` секунд (по умолчанию 15 минут) монитор подключается к каждой машине по SSH
2. На машине он собирает аптайм, нагрузку, использование памяти и диска
3. Если сессии бота нет, он запускает `bot_cmd` в tmux-сессии `bot` (или в фоне, если tmux не установлен)
4. Также он запрашивает `SITE_URL` и измеряет время ответа
5. После 3 неудачных проверок подряд отправляется оповещение, а когда цель восстанавливается, приходит уведомление о восстановлении
6. Команда `/check` запускает ту же проверку вручную, между проверками действует пауза 20 секунд

## Установка

Нужен Python 3.10 или новее.

1. Клонируйте репозиторий и установите зависимости:

```bash
pip install -r requirements.txt
```

2. Создайте `BANNED_FILES/.env` со своими настройками (см. ниже)
3. Скопируйте `BANNED_FILES/machines.example.json` в `BANNED_FILES/machines.json` и впишите свои машины
4. Запустите бота:

```bash
python main.py
```

Должен быть задан хотя бы один из `DISCORD_TOKEN` и `TELEGRAM_TOKEN`.

## Настройка

### Переменные окружения

Задаются в `BANNED_FILES/.env`:

| Переменная               | Назначение                                                        |
| ------------------------ | ----------------------------------------------------------------- |
| `DISCORD_TOKEN`          | токен Discord-бота (если пусто, Discord выключен)                 |
| `ALERT_CHANNEL_ID`       | канал Discord для оповещений                                      |
| `TEST_GUILDS`            | id серверов через запятую; слеш-команды появляются там мгновенно  |
| `TELEGRAM_TOKEN`         | токен Telegram-бота (если пусто, Telegram выключен)               |
| `TELEGRAM_ALERT_CHAT_ID` | чат или канал Telegram для оповещений                             |
| `GITHUB_REPO`            | репозиторий для `/history`, в виде `owner/name` или полной ссылки |
| `GITHUB_TOKEN`           | необязательно, повышает лимит запросов к GitHub API               |
| `APINEX_API_KEY`         | ключ для `/ai` (также подходит переменная `API`)                  |
| `AI_BASE_URL`            | адрес OpenAI-совместимого API                                     |
| `AI_MODEL`               | название модели                                                   |
| `SITE_URL`               | сайт для проверки (если пусто, проверка пропускается)             |
| `TIMEZONE`               | часовой пояс для часов, по умолчанию `Europe/Kyiv`                |
| `MACHINES_CONFIG`        | имя файла с машинами, по умолчанию `machines.json`                |

### Машины

`BANNED_FILES/machines.json`:

```json
{
  "host": "ssh.instabox.sh",
  "port": 2222,
  "interval": 900,
  "machines": [
    {
      "name": "machine1",
      "user": "YOUR_SSH_USER",
      "bot_cmd": "while true; do date >> ~/keepalive.log; sleep 60; done"
    }
  ]
}
```

| Поле      | Назначение                                                   |
| --------- | ------------------------------------------------------------ |
| `host`    | SSH-хост                                                     |
| `port`    | SSH-порт                                                     |
| `interval`| время между автоматическими проверками, в секундах           |
| `name`    | имя машины в карточках и оповещениях                         |
| `user`    | SSH-пользователь машины                                      |
| `bot_cmd` | команда, которая запускается на машине, если она не запущена |

Подключение идет без пароля и без ключей: значение `user` работает как учетные данные, поэтому держите этот файл в секрете.

### Оповещения

* **Server is down / Site is down** отправляется после 3 неудачных проверок подряд
* **Back online** отправляется, когда цель снова отвечает после такого сбоя
* **Bot restarted** отправляется, когда бота пришлось запустить заново на машине

## Безопасность

* `BANNED_FILES/.env` и `BANNED_FILES/machines.json` указаны в `.gitignore`, никогда не коммитьте их
* Токены, API-ключи и SSH-пользователи заменяются на `***` в терминале и в `logs/bot.log`
* Терминал показывает только короткие строки статуса. Полные трейсбеки идут в `logs/bot.log` (ротация, до 1 МБ на файл, 3 копии)
* Библиотеки заглушены ниже уровня WARNING, поэтому они не могут вывести ничего лишнего

## FAQ

**Бот не запускается.**
Проверьте, что в `BANNED_FILES/.env` задан `DISCORD_TOKEN` или `TELEGRAM_TOKEN`, а `machines.json` существует и содержит хотя бы одну машину.

**Слеш-команды не появляются в Discord.**
Глобальные команды могут появляться не сразу. Впишите id своего сервера в `TEST_GUILDS`, чтобы получить их сразу.

**Оповещений нет.**
Проверьте `ALERT_CHANNEL_ID` и `TELEGRAM_ALERT_CHAT_ID` и убедитесь, что бот может писать в этот канал или чат. Оповещения приходят только после 3 неудачных проверок подряд.

**Почему терминал почти пустой?**
Так задумано. Подробности лежат в `logs/bot.log`.

**Можно запустить только одного из ботов?**
Да. Оставьте второй токен пустым.
